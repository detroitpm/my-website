# Scope of Work job files

One JSON file per property — the output of Claude's `/build-sow` skill, ready to
load into the builder at `/sow.html` with the **Upload SOW file** button.

These are **job data, not website code**. Nothing on the site reads this folder;
moving, renaming or deleting a file in here can't break section8pm.com.

Named `sow-<address>.json`, e.g. `sow-8355-wisconsin-st.json`.
